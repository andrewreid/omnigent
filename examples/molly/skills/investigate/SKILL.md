# Read-only investigation

Orchestrator only. Load dispatch. Give one worker the question, bounded scope,
absolute repository path and evidence required, with purpose `explore` (repository)
or `search` (external sources). Use multiple workers only for independent questions
or a justified second lens. No source edits or publication.

Collect findings through the inbox. Distinguish results from announcements using
dispatch's recovery rules. Synthesize evidence and identify remaining uncertainty.
A disagreement can merit a targeted follow-up or architecture decision. A discovered
improvement does not authorize implementation: return to scope if fixing it is
part of the user's goal; otherwise report it as follow-up.
